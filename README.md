# Russia Watch — карта предупреждений

Публичная интерактивная карта региональных предупреждений, основанная на публикациях четырёх открытых Telegram-источников.

## Включить сайт

1. Откройте **Settings → Pages** этого репозитория.
2. В разделе **Build and deployment** выберите **Deploy from a branch**.
3. Выберите ветку **main** и папку **/docs**, затем нажмите **Save**.

Адрес сайта после публикации: https://johnnydelateling-bit.github.io/russia-watch-map/

## Подключить обновления от Telegram Monitor

Сайт получает публичный JSON в `docs/data.json`. Приватный монитор передаёт туда только опубликованные события с регионом, категорией, временем и ссылкой на исходную запись. Тексты сообщений, названия населённых пунктов, координаты и маршруты в публичный фид не записываются.

В FadeHost у приватного монитора добавьте `MAP_GITHUB_TOKEN` — отдельный fine-grained personal access token GitHub с доступом **только к этому репозиторию** и разрешением **Contents: Read and write**. Сам токен сюда, в репозиторий или в код сайта не добавляйте.

Дополнительные значения по умолчанию уже настроены в коде монитора:
- `MAP_GITHUB_REPOSITORY=johnnydelateling-bit/russia-watch-map`
- `MAP_GITHUB_BRANCH=main`
- `MAP_GITHUB_PATH=docs/data.json`

Публикуются только сообщения, которые уже отправлены монитором в Telegram и для которых регион распознан однозначно.

## Как читать карту

Подсветка отражает последнее распознанное опубликованное предупреждение по региону. Красивый или серый цвет не является официальным статусом опасности. Отсутствие отметки не означает отсутствие угрозы. Карта не заменяет официальные сообщения МЧС, региональных властей и экстренных служб.

Геометрия 89 субъектов взята из [karta-rossii](https://github.com/prokopenkoad42-creator/karta-rossii). Четыре области, обозначенные пунктиром, представлены согласно схеме исходного набора данных; их включение не означает международного признания статуса. Слой используется только для обзорной региональной визуализации.

## Технологии

HTML, CSS, JavaScript, Leaflet, TopoJSON. Внешние библиотеки Leaflet и topojson-client загружаются с unpkg CDN.
