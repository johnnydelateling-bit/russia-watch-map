Информация о карте

Ukraine Atlas — картографическая рабочая область на базе Leaflet. Поддерживаются справочные подложки, границы административных областей, поиск, локальный импорт KML/KMZ, объектное дерево, просмотр атрибутов, рисование геометрии и экспорт GeoJSON.

Источники

Подложки: OpenStreetMap, Esri и CARTO. Административные границы загружаются из ArcGIS Feature Service. Поиск населённых пунктов использует OpenStreetMap Nominatim.

Данные и приватность

Файлы KML/KMZ, выбранные пользователем, обрабатываются на устройстве. Они не отправляются в GitHub или на сервер карты. Из публичного репозитория невозможно получить содержимое импортированных локальных файлов.

Временные поля

В пяти переданных KMZ не обнаружены стандартные KML TimeStamp/TimeSpan. Поэтому хронологический фильтр для них нельзя корректно построить без дополнительных датированных источников.
